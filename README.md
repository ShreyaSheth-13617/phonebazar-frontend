# 🎨 PhoneBazar Frontend

Modern React frontend for PhoneBazar – a mobile marketplace platform.

## 🚀 Features

* Browse Mobile Listings
* Product Details Page
* Add to Cart
* Checkout with Razorpay
* Order Tracking
* User Authentication
* Admin Dashboard

## 🛠️ Tech Stack

* React.js
* Axios
* React Router
* CSS / Tailwind (if used)

## 📁 Project Structure

```
src/
 ├── components/
 ├── pages/
 ├── services/
 ├── assets/
```

## ⚙️ Environment Variables

Create `.env` file:

```
VITE_API_URL=http://localhost:5000/api
```

## ▶️ Run Locally

```
npm install
npm run dev
```

## 🌐 Backend Connection

Make sure backend is running at:

```
http://localhost:5000
```

## 📌 Notes

* Ensure backend is deployed before frontend
* Update API URL after deployment
